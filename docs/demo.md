# Демо перевода с русского на английский

Приложение на Streamlit для проверки модели на своих предложениях. Используется Seq2Seq LSTM с механизмом внимания Bahdanau и BPE-токенизацией SentencePiece.

Эта модель показала лучший результат среди трёх вариантов в проекте: **48.96 BLEU** на 82 408 тестовых парах. Сравнение выполнено через SacreBLEU в [04_model_comparison.ipynb](../04_model_comparison.ipynb).

Обучение и результаты экспериментов описаны в [README.md](../README.md). Для запуска демо достаточно готовых весов и токенизаторов.

## Запуск

Из корня проекта:

```bash
python -m pip install -r requirements-demo.txt
python -m streamlit run app.py
```

После запуска откройте адрес из терминала, обычно `http://localhost:8501`. Введите предложение на русском и нажмите «Перевести».

Приложение использует GPU, если установлен PyTorch с поддержкой CUDA и доступна видеокарта. Иначе перевод выполняется на CPU. Модель загружается при первом переводе и остаётся в памяти для следующих запросов.

## Нужные файлы

В проекте должны быть веса и оба токенизатора:

```text
models/best_bpe_attention.pt
artifacts/tokenizers/ru_bpe.model
artifacts/tokenizers/en_bpe.model
```

Используйте токенизаторы, с которыми обучалась модель. При изменении словаря или соответствия токенов и ID старые веса становятся несовместимы с новым токенизатором. Датасет для запуска демо не нужен. После замены весов или токенизаторов перезапустите приложение.

## Примеры и ограничения

Ниже — переводы текущей модели, включая ошибки:

| Вход | Перевод модели | Комментарий |
| --- | --- | --- |
| Мне пора идти спать. | It's time for me to go to bed. | Корректный перевод |
| Мне пора идти спать | I was time for go to bed. | Без точки модель ошибается во времени и построении фразы |
| Кто оставил ключи на столе? | Who left the keys keys? | Повтор слова и пропуск места |
| Поезд отправляется в 17:45. | The train leaves at 1:4454. | Искажено время |

Модель обучалась на парах предложений длиной до 30 слов с каждой стороны. В ручных примерах встречаются повторы, пропуски слов, ошибки в числах и буквальный перевод идиом. Результат может меняться из-за пунктуации. Качество перевода длинных текстов отдельно не оценивалось.

BLEU считается по всей тестовой выборке и не гарантирует правильность отдельного перевода. У текущего разбиения также есть ограничение: часть русских предложений встречается и в обучающей, и в тестовой выборке с разными английскими переводами.

## Перевод из Python

Код выполняется из корня проекта:

```python
from src.inference import load_model, translate_sentence

bundle = load_model(
    name="bpe_attention_lstm",
    checkpoint_path="models/best_bpe_attention.pt",
    ru_model_path="artifacts/tokenizers/ru_bpe.model",
    en_model_path="artifacts/tokenizers/en_bpe.model",
    device="cpu"
)

translation = translate_sentence("Мне пора идти спать.", bundle)
print(translation)
```

`load_model` достаточно вызвать один раз. Для запуска на GPU укажите `device="cuda"`. Требуется доступная CUDA.

Загрузка модели находится в `src/inference.py`, генерация перевода — в `src/generation.py`, интерфейс — в `app.py`. При генерации на каждом шаге выбирается самый вероятный токен (greedy decoding). Перевод заканчивается при появлении токена конца последовательности или достижении лимита в 50 токенов.
